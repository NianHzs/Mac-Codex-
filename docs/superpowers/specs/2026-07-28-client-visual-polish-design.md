# Codework AI 晴空轻透界面优化设计

## 目标

将 Windows 客户端默认界面统一为“晴空轻透”风格，同时保留蜡笔小新、凯蒂猫和自定义壁纸的独立个性。所有页面在明暗不同的壁纸下都应保持文字、窗口按钮和交互控件清晰可读。

## 范围

本轮覆盖侧栏、首页、设置、聊天、通知浮层、模态弹窗和窗口顶部区域。令牌、Skill、市集、身份、聊天协议等业务功能保持不变；本轮只调整视觉层级、主题状态和交互反馈。

## 视觉原则

### 晴空轻透默认风格

- 默认背景使用低饱和天空蓝、雾白和少量暖色高光，避免大面积强粉色。
- 左侧栏使用浅蓝雾面底色；选中项为低饱和蓝色圆角胶囊。
- 内容卡片使用 14px 圆角、1px 淡蓝灰边框和轻阴影；不叠加厚重黑边或多层描边。
- 信息层级固定为标题、说明、操作三层，避免同一页面出现多种字号、圆角和阴影规则。

### 阅读层优先

主题由三个互不混淆的层组成：

1. 背景层：仅绘制默认渐变、官方主题或用户自定义壁纸。
2. 阅读层：首页、设置、聊天和弹窗的浅色半透明表面；根据壁纸亮度调节透明度与模糊，不直接修改业务文本颜色。
3. 交互层：文字、图标、输入框、消息气泡、皇冠、版本号、窗口控制和按钮，始终使用具有足够对比度的前景色。

自定义壁纸仅影响背景层和轻微强调色。它不得覆盖或染色阅读层、聊天消息、顶部窗口控制或身份颜色。

## 组件规范

### 侧栏与顶栏

- 侧栏导航使用统一 10px 内圆角和 8px 垂直间距。
- 当前页面使用浅蓝背景、深蓝文字和低调阴影；非当前页面仅在悬停时显示浅蓝反馈。
- 顶栏使用独立的高对比阅读层。版本号、皇冠、最小化、最大化和关闭按钮不能依赖壁纸颜色。
- 皇冠颜色继续由身份决定，不被全局主题主色覆盖。

### 首页、设置与浮层

- 卡片使用统一的表面颜色、边框和阴影 token。
- 按钮只使用主按钮、次按钮和危险按钮三类视觉层级。
- 通知、好友、令牌和 Skill 浮层使用浅透白色表面及 16px 圆角；阴影用于分层，不使用纯黑大块背景。

### 聊天

- 聊天窗口始终使用独立阅读面板，不让壁纸直接出现在消息文字后。
- 对方消息使用中性浅灰蓝；自己的消息使用柔和天蓝，避免高饱和荧光绿或过亮粉色。
- 头像、状态、已读、时间戳和未读角标使用固定对比度规则。

## 主题状态与容错

- 启动时先加载持久化的主题配置，再渲染阅读层，避免短暂出现默认粉色或错误自定义壁纸。
- 自定义图片从图像本身提取强调色；图片提取失败时使用晴空蓝 fallback，不使用固定粉色。
- 隐藏侧栏、切换页面、打开聊天或调整窗口大小不能卸载背景层。
- 透明度和模糊度滑杆即时更新 CSS 变量并持久化。数值非法时恢复到安全默认值，控件仍可继续使用。

## 验收标准

- 默认、蜡笔小新、凯蒂猫和自定义图片分别验证首页、设置、聊天和浮层。
- 在浅色、深色和高饱和自定义图片下，正文、按钮、版本号、皇冠及窗口控制均可清晰辨认。
- 隐藏/显示侧栏、打开/关闭聊天、窗口缩放、切换页面和重启客户端后，主题不消失、不留白、不发生错位。
- 透明度、模糊度和壁纸选择立即生效，重启后保持上次设置。
- 前端类型检查、主题状态单元测试及关键 CSS/DOM 断言全部通过。
