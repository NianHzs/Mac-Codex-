# Skill 市场设计说明

## 目标

将现有依赖第三方 GitHub 的“脚本市场”替换为 **Skill 市场**。用户可在客户端浏览、安装并更新由 Codework AI 官方发布的中文 Codex Skills；技能内容更新不要求重新安装客户端。

## 范围

首发六个技能：

1. 智能文案助手
2. 短视频脚本助手
3. 表格数据助手
4. 文件整理助手
5. 代码排错助手
6. 项目搭建助手

Skill 市场只安装官方清单中列出的技能。文件整理助手的 SKILL.md 必须要求先输出文件预览、影响范围和操作方案，并在用户明确确认前不执行移动、重命名或删除。

## 架构

GitHub 仓库保存每个 Skill 的源码、版本记录和发布材料。客户端不直接访问 GitHub，而是从 1Panel 服务器读取镜像清单和 ZIP 包，避免国内网络访问 `raw.githubusercontent.com` 不稳定。

客户端将使用固定的官方清单地址：

```text
http://115.190.199.191:20080/downloads/codework-skills/index.json
```

清单包含每个技能的稳定 ID、中文名、描述、版本、标签、ZIP 下载地址和 SHA-256。安装器只接受合法 ID，从清单中取地址，下载后核对 SHA-256，安全解压到 `%USERPROFILE%/.codex/skills/<skill-id>/`。解压时拒绝绝对路径、`..` 路径穿越和符号链接。

## 客户端体验

左侧菜单名称为 **Skill 市场**。页面展示中文卡片、技能说明、版本、标签和“安装 / 已安装 / 更新”状态；刷新只刷新官方 Skill 清单。安装或更新成功后，用户可立刻在 Codex 内使用相应技能；页面同时显示当前安装版本。

原有第三方 JS 用户脚本入口不再从该页面加载，以免继续触发 BigPizzaV3 地址的报错。兼容性相关旧数据不删除，但 Skill 市场不会把 JS 脚本当作 Skill 安装。

## 出错与安全处理

网络不可用、清单无效、哈希不符、ZIP 缺少 `SKILL.md` 或包含危险路径时，安装不写入任何技能文件，并展示中文可读错误。已安装版本保留不受失败更新影响。

## 验收

- 不再请求 BigPizzaV3 脚本市场地址。
- Skill 市场首发显示六个中文技能。
- 安装后对应目录包含 `SKILL.md`，并显示已安装版本。
- 更改服务器清单或技能 ZIP 后，客户端刷新即可发现更新。
- 哈希错误和路径穿越的 ZIP 被拒绝且不会落盘。
- 文件整理助手明确要求“先预览、后确认”。
