# Codework AI 动态壁纸设计

## 目标

让 Codework AI 的凯蒂猫、蜡笔小新和用户自定义壁纸具备柔和的动态效果，同时不影响聊天、导航、身份信息和窗口控制按钮的可读性。

## 视觉与交互

- 动效只作用于最底层的壁纸图层：使用低幅度的平移与缩放循环，不移动任何业务界面元素。
- 凯蒂猫使用轻柔云端漂浮效果；蜡笔小新使用较活泼但同样低幅度的平移；自定义壁纸使用通用缓动效果。
- 自定义壁纸始终保留原图色彩。界面强调色根据图片主色生成中性、可读的色板，不再统一附加粉色调。
- 左侧栏、顶部栏、聊天卡片和输入框使用独立的半透明磨砂层；身份皇冠、按钮与强调色随主题色板协调变化。
- 个性化面板提供“动态壁纸”总开关。关闭时保留原壁纸与现有透明度、模糊度设置，只移除动画。

## 运行机制

1. 主题运行时注入一个独立的 `wallpaper-motion` 背景层。
2. 背景层读取当前已验证的官方主题资源或 Codework 管理的自定义壁纸资源。
3. 当前主题切换、左侧栏收起、页面路由切换时只更新背景资源和色板，不清理主题根节点。
4. 窗口失焦、文档隐藏或系统启用“减少动态效果”时暂停动画；重新聚焦后恢复。
5. 无法加载动画层时自动降级为当前静态壁纸，不阻塞客户端启动。

## 性能与兼容性

- 仅使用 CSS `transform` 与 `opacity` 动画，不进行逐帧 Canvas 渲染。
- 动画时长为 14–22 秒，避免高频、眩晕式移动。
- 不改变 Codex 原生 DOM 结构，也不依赖左侧栏是否存在。
- Windows 版本优先实现；已有静态主题与自定义壁纸仍可正常使用。

## 验收与测试

- 三种主题均能显示各自原图，并可看到背景独立移动。
- 左侧栏隐藏、恢复后主题与动效仍然保留。
- 自定义壁纸不会出现统一粉色覆盖或留白。
- 聊天页面、首页、右上角窗口按钮和身份信息保持清晰、可操作。
- 关闭总开关、窗口失焦和“减少动态效果”均能暂停动画并保留静态画面。
- 回归现有 Dream Skin 注入测试与 Windows 打包测试。
